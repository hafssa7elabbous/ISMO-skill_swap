# ISMO-skill_swap
ISMO-SkillSwap, réseau web collaboratif dédié au dépannage technique et à la gestion des acquis. Publication de tickets d'assistance, évaluation des mentors, certification des modules par les enseignants, attribution de badges, édition de Passeports de Compétences au format PDF, moteur de recherche multicritères et indicateurs statistiques avancés.
